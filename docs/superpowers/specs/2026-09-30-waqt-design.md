# Waqt — виджет времени намаза (спецификация)

## Цель
Небольшое окно 200×200 px, всегда поверх всех окон, которое показывает обратный отсчёт до конца текущего намаза, напоминает звуком, позволяет отмечать прочитанные намазы и хранит историю (зелёный / красный / жёлтый / серый) с синхронизацией в Supabase.

## Решения (итог обсуждения)
- Платформа: Windows 11, Electron, автозапуск с Windows, позиция окна запоминается.
- Город: Астана (51.133333, 71.433333), фиксированный, в конфиге.
- Источник времён: `https://api.muftyat.kz/prayer-times/{год}/51.133333/71.433333` (поля imsak, fajr, sunrise, dhuhr, asr, sunset, maghrib, isha, midnight, Date). Используются только данные на сегодня; обновление при запуске и каждые 5 часов, кэш на диск.
- Стиль: как виджеты sajda.com (sajda.png): белая скруглённая карточка, очень крупные жирные цифры, оранжевая подпись, зелёная круглая иконка, арабская каллиграфия для имён; пастельный фон.
- Язык интерфейса: русский.

## Окна намаза
| Намаз | Начало | Конец окна |
|-------|--------|------------|
| Фаджр | fajr | sunrise |
| Зухр | dhuhr | asr |
| Аср | asr | sunset |
| Магриб | maghrib | isha |
| Иша | isha | fajr следующего дня |

Между окнами (восход→зухр, закат→магриб) обязательного намаза нет: показывается «до следующего».

## Виджет 200×200
- Без рамки, скруглённая белая карточка, alwaysOnTop, перетаскивается, позиция сохраняется.
- Верх: оранжевая подпись («ФАДЖР — ДО КОНЦА» / «ДО ЗУХР»), справа зелёная иконка открытия истории.
- Центр: таймер. `Ч:ММ`, при < 15 минут `ММ:СС`. Цвет цифр: чёрный; < 30 мин красный; < 15 мин бордовый. Меняется только цвет цифр.
- Кнопка-галочка «прочитал» (только в окне намаза): статус `on_time`, звук для этого намаза отключается. Если сегодня есть красный намаз, рядом индикатор для отметки «прочитан позже» (`late`, жёлтый).
- В промежутке между намазами: имя Аллаха дня (арабское, транслитерация, перевод); клик переворачивает карточку с описанием. Одно имя в день по дате.
- Низ: 5 точек статусов сегодняшних намазов (зелёный, красный, жёлтый, серый для ещё не наступившего).

## Звук
Короткий мягкий сигнал (`assets/chime.wav`) на 20, 15, 10 и 5 минутах до конца окна, если намаз не отмечен. Играет и при скрытом окне (backgroundThrottling выключен). Громкость фиксированная.

## История
- Клик по иконке: то же окно анимированно растёт до ~900×600 к центру экрана, содержимое сменяется таблицей. В этом режиме alwaysOnTop выключен. Закрытие возвращает 200×200 на прежнюю позицию.
- Таблица как example.png: дни колонками, пять намазов строками; навигация по неделям и месяцам; хранится вся история.
- Цвета: зелёный — прочитан вовремя; красный — окно закончилось без отметки; жёлтый — прочитан позже; серый — нет данных за день (приложение не запускалось).
- Клик по красной ячейке → жёлтая. Клик по зелёной/жёлтой → отмена отметки. Красная не превращается в зелёную. Для серого дня отметка всегда `late`.
- Fallback анимации (если мерцает): 8–10 ступеней с кроссфейдом.

## Трей
«Показать/Скрыть», «История», «Выйти», «Войти в аккаунт». Закрытие окна прячет в трей. Single instance.

## Данные
Локальный JSON в `%APPDATA%` — основной источник; синхронизация в Supabase в фоне (очередь, повтор при появлении сети и запуске).

Supabase (проект `xzmezgwdwqrfgbhxgdsu`, URL `https://xzmezgwdwqrfgbhxgdsu.supabase.co`), доступ по publishable-ключу + вход email/пароль (существующая учётка). RLS: `user_id = auth.uid()`.
- `prayer_days(user_id, date, times jsonb)` — запись создаётся при запуске в день; означает «день отслеживался».
- `prayer_marks(user_id, date, prayer, status, marked_at, updated_at)`, уникально (user_id, date, prayer); статус `on_time` | `late`.
- Красный вычисляется, не хранится.
- Конфликты: побеждает более поздняя `updated_at`; отмена = удаление строки.
- Секреты: только publishable key в `.env` (в `.gitignore`). Secret key и пароль БД не используются.

## Модули
```

src/core/        computeState, prayer-times, reminders, names, store, sync, auth
src/renderer/    widget/, history/
assets/          chime.wav, names.json (99 имён: azan.kz, арабское написание добавляется, описание сокращено)
```

`computeState(times, marks, now)` — чистая функция: текущий намаз, остаток, уровень цвета, следующий намаз, статусы точек.

## Ошибки
- Нет сети и нет кэша: «Нет данных о времени», повтор раз в минуту.
- Полночь: Иша до fajr следующего дня; после полуночи отметка пишется на вчерашнюю дату.
- Ошибка входа: работа локально, индикатор «не синхронизировано», повтор входа из трея.
- Повреждённый JSON: бэкап, начать заново, подтянуть из Supabase.

## Тестирование
Юнит-тесты: `computeState` (границы, полночь, пороги 30/15), reminders (какие сигналы и когда), слияние локальных и удалённых отметок. UI — вручную с подменой времени.

## Вне рамок (YAGNI)
Выбор города, настройка громкости, экспорт, азан, уведомления мобильные.
