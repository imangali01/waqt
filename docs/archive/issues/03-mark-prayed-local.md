# 03: Кнопка «прочитал» и локальная история сегодняшнего дня

**What to build:** в окне намаза под таймером появляется кнопка-галочка. Нажатие отмечает текущий намаз как прочитанный вовремя и сохраняет в локальный файл. Внизу виджета пять точек по статусам сегодняшних намазов: зелёная (вовремя), красная (окно закончилось без отметки, вычисляется), жёлтая (прочитан позже), серая (ещё не наступил). Если есть красный намаз, рядом с кнопкой индикатор, по нему пропущенный намаз отмечается как прочитанный позже (жёлтый).

- [ ] Отметка сохраняется локально и переживает перезапуск
- [ ] Красный статус вычисляется, не хранится
- [ ] Пять точек статусов внизу виджета
