# 06: Трей, автозапуск, позиция окна

**What to build:** иконка приложения в системном трее с меню «Показать/Скрыть», «История», «Выйти». Закрытие окна прячет его в трей, а не завершает приложение. Приложение запускается вместе с Windows. Позиция окна сохраняется между запусками. Второй запуск не создаёт копию, а показывает уже запущенное окно.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Меню трея с тремя пунктами работает
- [ ] Закрытие окна прячет его, приложение продолжает считать время
- [ ] Автозапуск с Windows включается при первом запуске
- [ ] Позиция окна запоминается и восстанавливается
- [ ] Второй экземпляр не запускается, показывается первый
