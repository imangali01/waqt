# 05: Имя Аллаха дня

**What to build:** в промежутках между намазами карточка показывает имя Аллаха дня: арабское написание, транслитерацию и перевод. Клик по имени переворачивает карточку и показывает краткое описание. Имя одно на день (по дате). Данные 99 имён собираются с azan.kz (страницы с уроками), арабское написание добавляется, описания сокращаются до 1–2 предложений, всё хранится в локальном файле. Пользователь проверяет тексты.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Локальные данные содержат все 99 имён с переводом и описанием
- [ ] Имя выбирается по дате и не меняется в течение дня
- [ ] Клик переворачивает карточку на описание и обратно
- [ ] Имя показывается только в промежутках между намазами
- [ ] Пользователь просмотрел тексты
