# 01: Виджет с таймером до конца намаза

**What to build:** приложение запускается как окно 200×200 без рамки, всегда поверх всех окон. Оно берёт время намазов на сегодня из API muftyat.kz (Астана), кэширует на диск и показывает название текущего намаза и обратный отсчёт до конца его окна в формате `Ч:ММ`. Окна: Фаджр до восхода, Зухр до асра, Аср до заката, Магриб до иши, Иша до фаджра следующего дня. Между окнами показывает «до следующего» с таймером. Стиль: белая скруглённая карточка, крупные жирные цифры, оранжевая подпись (как виджеты sajda). Логика в чистой функции состояния, покрытой тестами.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Окно 200×200, без рамки, поверх всех окон, перетаскивается мышью
- [ ] Время на сегодня загружается из API и кэшируется на диск
- [ ] Показывается текущий намаз и остаток до конца его окна
- [ ] В промежутках показывается «до следующего» с таймером
- [ ] Иша после полуночи считается до фаджра (окно вчерашней иши)
- [ ] Юнит-тесты функции состояния: границы окон, полночь, промежутки
