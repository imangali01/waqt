# 08: Синхронизация с Supabase

**What to build:** локальные отметки и записи «день отслеживался» синхронизируются с Supabase в фоне. Схема (таблицы дней и отметок с защитой строк по владельцу) оформляется SQL-файлом, который пользователь запускает в SQL Editor. Вход по email и паролю существующей учётки при первом запуске, сессия сохраняется и обновляется. Отметки пишутся сначала локально, при появлении сети отправляются из очереди. Конфликты решает более поздняя дата изменения; отмена отметки синхронизируется как удаление. Ошибка входа не мешает работе: показывается индикатор «не синхронизировано», вход можно повторить из трея. На другом ПК после входа подтягивается вся история.
