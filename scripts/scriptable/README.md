# Виджет Waqt для iPhone (Scriptable)

1. Установите бесплатное приложение **Scriptable** из App Store.
2. В Scriptable нажмите «+», вставьте всё содержимое `Waqt.cjs`, назовите скрипт «Waqt».
3. На домашнем экране: долгое нажатие → «+» → Scriptable → малый виджет → «Изменить виджет» → Script: Waqt.
4. Язык задаётся в поле Parameter: `ru`, `kk` или `ar` (по умолчанию `ru`).

Таймер тикает сам. Цвет меняется за 30 и 15 минут до конца окна, для этого iOS перезапускает виджет в нужные моменты
(точность зависит от iOS, возможна задержка в несколько минут). Отметки «прочитал», серия, звуки и азан не поддерживаются.
