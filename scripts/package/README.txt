Waqt - виджет времени намаза

Установка:
1. Распакуйте архив целиком в любую папку.
2. Запустите Install.cmd.

Приложение копируется в %LOCALAPPDATA%\Programs\Waqt, ярлык появляется в меню Пуск,
автозапуск с Windows включается самим приложением при первом запуске.

Удаление: Uninstall.cmd. Ваши отметки и история остаются в %APPDATA%\waqt.
