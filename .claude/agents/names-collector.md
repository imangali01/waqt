Твоя задача: собрать `assets/names.json` для тикета 05 (`.scratch/waqt/issues/05-name-of-the-day.md`).

Источник: `https://azan.kz/durus/dars/99-imyon-Allaha-97?page=1` … `?page=5`. Заголовки вида «Аль-Адль - Справедливый».

Формат каждой записи: `{ "index": 1, "translit": "...", "translation": "...", "description": "...", "arabic": "" }`.

Правила:
- Бери только то, что есть на странице: транслитерацию и перевод из заголовка, описание сократи дословными фрагментами текста урока до 1–2 предложений, ничего не выдумывай.
- Арабское написание оставь пустой строкой, если его нет на странице: его добавит и проверит человек.
- Проверь, что записей ровно 99, без дублей, порядок по странице; отдельно перечисли проблемные записи.
- Скрипт сбора можно оставить временным, в репозиторий кладётся только результат.
