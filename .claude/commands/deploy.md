Задеплой сайт Waqt на Vercel строго по инструкции [docs/deploy-vercel.md](../../docs/deploy-vercel.md).

1. Прочитай `docs/deploy-vercel.md`.
2. Убедись, что изменения закоммичены и запушены в `main` (деплоить стоит из актуального `main`).
3. Выполни из корня проекта команду из инструкции (токен берётся из `~/.vercel-token`, в чат и файлы его не копировать).
4. Сообщи адрес: https://waqt-timer.vercel.app (веб-виджет `/app/`) и результат деплоя.

Если режим разрешений блокирует прод-деплой, не обходи блокировку: объясни пользователю и дай команду для запуска самому.
